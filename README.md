### 🇷🇺 Русский (Russian)

<kbd>📌</kbd> **Описание**  
Это современная, стильная и интерактивная страница авторизации (Login), созданная с использованием HTML5, CSS3 и JavaScript. Проект выполнен в стиле Neumorphism (неоморфизм), полностью адаптивен под мобильные устройства и включает в себя переключение видимости пароля, а также кнопки для входа через социальные сети.

<kbd>🛠️</kbd> **Технологии**  
* <kbd>🌐</kbd> **HTML5** - Структура страницы
* <kbd>🎨</kbd> **CSS3** - Стили, анимации и эффекты неоморфизма
* <kbd>📱</kbd> **Media Queries** - Адаптивность под телефоны и планшеты
* <kbd>⚡</kbd> **JavaScript** - Интерактивность и показ/скрытие пароля
* <kbd>📦</kbd> **Font Awesome** - Иконки интерфейса

### 🇬🇧 English (English)

<kbd>📌</kbd> **Description**  
This is a modern, stylish, and interactive login page built with HTML5, CSS3, and JavaScript. The project features a clean Neumorphism design, full responsiveness across all screen sizes, password visibility toggle functionality, and social media login buttons.

<kbd>🛠️</kbd> **Technologies Used**  
* <kbd>🌐</kbd> **HTML5** - Markup structure
* <kbd>🎨</kbd> **CSS3** - Styling, animations, and Neumorphic effects
* <kbd>📱</kbd> **Media Queries** - Mobile and tablet responsiveness
* <kbd>⚡</kbd> **JavaScript** - Interactivity and password toggle logic
* <kbd>📦</kbd> **Font Awesome** - UI icons
